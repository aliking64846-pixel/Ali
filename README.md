# نظام المقاولات الذكي Ali V2

نسخة مقسمة إلى ملفات مستقلة بواجهة عربية RTL.

## التشغيل
- الصفحة الرئيسية هي index.html.
- انشر الملفات في جذر المستودع وفعّل GitHub Pages.
- يجب فتح الموقع عبر HTTP/HTTPS حتى تعمل JavaScript ES Modules.

## البنية
- css/main.css: التصميم الأساسي.
- css/responsive.css: توافق الهاتف والطباعة.
- js/database.js: التخزين المحلي.
- js/calculations.js: الحسابات المالية.
- js/app.js: الواجهات والعمليات والتنقل.

## حدود الإصدار
يستخدم الإصدار LocalStorage في المتصفح الحالي فقط. لا يوجد خادم خلفي أو تسجيل دخول أو مزامنة سحابية. احتفظ بنسخ احتياطية خارج الجهاز ولا تخزن بيانات حساسة.
